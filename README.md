# Ahava Morse Developer
Support Website for Ahava Morse Developer Apps


## Privacy
None of my apps collect any of your data. All content and preferences are stored on device.

## Support
If you would like to report a bug or make a feature suggestion you have two options.
1. Send an email to ahavamorsedeveloper@icloud.com
2. Tap 'Issues' above then 'New Issue' to create a support request

Please include the following information:
- The app you're having issues with
- A description of the issue
- A screenshot or recording (if possible)
